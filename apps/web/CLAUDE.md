# Tellia Force Web — notes for AI agents

Front for the hackathon app. **Vite + React 19 + Tailwind 4**, wrapped for
**Android with Capacitor**. See design context in Notion (link in root `CLAUDE.md`).

## Stack
- **React 19 + Vite 6 + Tailwind 4** (`@tailwindcss/vite`, CSS `@import "tailwindcss"`).
- **Capacitor → Android.** `capacitor.config.ts` (appId `com.tellia.force`,
  webDir `dist`). The `android/` native project is generated by `cap add android`.
- **`@tellia/shared`** (pnpm workspace) = all contracts (incl. the generated DB
  row schemas `tableSchemas`). The API client in `src/lib/api.ts` parses every
  response with the shared Zod schema → fails loud on backend/DB drift.
- **No Supabase in the front.** The web app talks ONLY to the API
  (`VITE_API_URL`). All DB access is server-side in `apps/api`.

## Native-aware, reusable components (`src/components/`)
Build mobile UI from these — they no-op gracefully on web:
- `Screen` — full-height wrapper honoring safe-area insets (notch/nav bar).
- `ui/Button` — big tap target + haptic feedback on press + variants.
- `ui/Card` — surface.
- `ShareButton` — native share sheet (`@capacitor/share`), falls back to Web Share.
Hooks: `useHaptics` (`@capacitor/haptics`), `useBackButton` (Android hardware back
via `@capacitor/app`). Platform helpers: `lib/native.ts` (`isNative`, `platform`,
`initNative`). **Always guard native plugin calls with `isNative`.**

## Commands
- Dev: `pnpm dev` (Vite, host:true so a phone on the LAN can reach it).
- Build: `pnpm build` (`tsc -b` + `vite build`).
- Android: `pnpm cap:sync` (after build) → `pnpm cap:open` (Android Studio) or
  `pnpm cap:run`. First time: `pnpm build && npx cap add android`.
- Live reload on device: `vite --host`, then set `server.url` in
  `capacitor.config.ts` to your LAN IP and `cap sync`.
